# Content Skills

Bộ 15 skill quy trình làm **content** (viết bài, làm video, content marketing), chuyển đổi từ bộ [Superpowers](https://github.com/trinhtphat/superpowers) (vốn dành cho lập trình) sang ngữ cảnh sáng tạo nội dung. Toàn bộ viết bằng tiếng Việt.

## Ánh xạ khái niệm

| Superpowers (code) | Content Skills |
|---|---|
| code | bài viết / content |
| test | kiểm chứng (đọc thử, check fact, đọc to) |
| bug | bài flop / bài có vấn đề |
| commit | lưu bản nháp |
| PR / merge | xuất bản |
| spec | content brief |
| plan | kế hoạch content |

## Danh sách skill

| Skill | Dùng khi |
|---|---|
| `brainstorming` | Trước mọi việc content: phân loại (test ý tưởng nhanh / 1 bài đơn lẻ / series-chiến dịch), đào sâu mục đích-đối tượng-góc nhìn, trình bày brief chờ duyệt |
| `using-superpowers` | Bootstrap: bắt buộc gọi skill phù hợp trước mọi hành động |
| `writing-plans` | Viết kế hoạch content chi tiết (hook, outline, nguồn, CTA, kênh, deadline từng bài) |
| `executing-plans` | Tự thực thi kế hoạch content task-by-task trong phiên hiện tại |
| `test-driven-development` | **Hook-first**: không viết full bài khi chưa chốt hook; kiểm chứng hook "dính" trước |
| `systematic-debugging` | Bài flop: tìm nguyên nhân gốc (đọc số liệu retention/CTR, trace hành trình người xem) trước khi viết lại |
| `subagent-driven-development` | Giao từng task content cho subagent mới + review sau mỗi task |
| `dispatching-parallel-agents` | Chia việc song song (research, viết, edit) cho các agent độc lập |
| `using-git-worktrees` | Không gian nháp cô lập cho từng bài/series |
| `finishing-a-development-branch` | Checklist xuất bản: đọc full, check fact, chính tả → đăng ngay / lên lịch / giữ nháp |
| `requesting-code-review` | Nhờ editor (subagent) review bài trước khi đăng |
| `receiving-code-review` | Nhận feedback biên tập đúng cách: verify trước khi sửa |
| `verification-before-completion` | Không tuyên bố "xong" khi chưa có bằng chứng kiểm chứng mới |
| `writing-skills` | Viết skill content mới (phương pháp Hook-first cho tài liệu) |
| `diagnosing-superpowers` | Chẩn đoán khi quy trình content trục trặc |

## Cài đặt

Copy từng thư mục trong `skills/` vào thư mục skills của công cụ bạn dùng, ví dụ:

- Muse AI: `~/workspace/skills/<tên-skill>/`
- Claude Code: `~/.claude/skills/<tên-skill>/`

Mỗi skill tự đủ: `SKILL.md` (đọc đầu tiên) + `references/` (đọc khi tới bước cần).
